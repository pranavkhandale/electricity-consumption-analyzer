# Electricity Consumption Analyzer

A Python application using NumPy to analyze electricity consumption patterns across different houses.

## Features
- Calculate total electricity consumption
- Calculate average consumption
- Identify high consumption houses (above 280 units)
- Find houses below average consumption
- Calculate consumption percentage for each house
- Find house with highest consumption
- Find house with lowest consumption
- Detailed consumption analysis and reporting

- ## How to Run
1. Install NumPy:
pip install numpy

2. Clone this repo:
git clone https://github.com/pranavkhandale/electricity-consumption-analyzer.git

3. Run the file:
python electricity_consumption_analyzer.py
